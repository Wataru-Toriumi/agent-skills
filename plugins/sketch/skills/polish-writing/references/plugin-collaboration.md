# 他のプラグインから受け取る場合

ink・forge・probe・pulse から渡された内容を、指定された読者・目的・形式に合わせて表現する。

1. 対象の本文・資料、変更範囲、残すべき条件と根拠、出力先を確認する。元のスキルの必須項目・書式・操作範囲を引き継ぎ、分かっている情報を聞き直さない。
2. 文章・図・スライド・HTMLを、依頼された範囲で作成する。文書や報告を整えるために、製品コード・検証モデル・監視設定を変えない。
3. 原文・資料と照合する。要求や例外、レビューの根拠と優先度、検証の仮定・範囲・実施状況、障害の事実と仮説、担当や期限の確定状況を保つ。情報不足や矛盾は確認事項として返し、採否・合否・原因を代わりに決めない。
4. 指定形式の成果物と、残った確認事項、実施した文章検査・描画確認と未確認範囲を呼び出し元へ返す。呼び出し元が内容と統合結果を照合できるよう、参照先と図の編集用ソースを保つ。

内容の判断は呼び出し元で行い、同じ仕上げを相互に呼び出し続けない。文章や描画の確認は、元の設計・コード・検証結果の再検証や承認を意味しない。
投稿・公開・通知は連携を理由に追加せず、元の依頼の範囲に従う。
