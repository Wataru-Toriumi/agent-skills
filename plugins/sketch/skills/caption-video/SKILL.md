# 動画に字幕を付ける

元動画、字幕に使う言語、台本や既存字幕、納品形式を確認する。元動画と元の字幕を保ち、指定がなければ別名の字幕付き MP4 と、それに使った SRT を渡す。字幕ファイルだけを依頼されたら SRT まででよい。

焼き込みや自動文字起こしの環境を用意するときは、[字幕ツールの導入手順](references/setup.md)を参照する。

## 素材から字幕を起こす

動画の長さと音声トラックを調べ、映像と音を確認する。音声トラックに環境音しかない操作デモもある。依頼と素材に応じて次の手順を選ぶ。

| 素材 | 字幕と時刻の決め方 |
| --- | --- |
| ナレーション | 発話を聴くか、利用できるローカルの音声認識で時刻付きの草案を作る。声の開始・区切りに合わせ、否定、数値、製品名、コマンドの綴りを音声・台本・画面と照合する。聞き取れない箇所は時刻を控えて確認する。 |
| 無音の操作デモ | 操作の直前・直後の映像を見て、どこを操作したか、何が変わったかを短く書く。操作対象が見える間に読み切れる位置と時間を選ぶ。台本と映像が食い違う箇所は確認事項にする。 |
| 既存の SRT | 対象動画と版が合うか、冒頭と後半の字幕を再生して確かめる。文言だけの修正なら時刻を保つ。同期の修正なら、全体が一定時間ずれているか、特定区間からずれるかを確認して対象を絞る。 |

文字起こしに外部サービスを使う場合、動画・音声の送信は依頼で認められた範囲に限る。

## 字幕を整えて書き出す

1. 発話や動作のまとまりで字幕を区切る。長い行は語句の切れ目で折り返し、ボタン名・コマンド・数値と単位は一緒に読めるようにする。
2. UTF-8 の SRT を作り、各区間の開始・終了を動画の再生時刻と照合する。空の字幕、逆転、尺を超える字幕、意図しない重なりを直す。
3. [文字起こしと焼き込みの実行例](references/rendering.md)に沿って SRT を動画に焼き込む。元の音声と画面の縦横比を保ち、実際の表示サイズで読める文字と縁取りを選ぶ。下部に操作対象があれば、字幕を上部や余白へ移す。
4. 出力 MP4 を再生し、冒頭・終盤、字幕の切り替わり、長い行、操作が密な場面を見る。音ずれ、文字化けや欠け、操作対象との重なりを直して再出力する。確認できた範囲と成果物を渡す。焼き込み環境が足りない場合は、完成した SRT と MP4 に残る作業を伝える。

スライドへの挿入も依頼された場合は、確認した MP4 を [create-slides](../create-slides/SKILL.md) に渡す。
